L'utilitaire de ligne de commande `i2cget` peut être utilisé pour tester des lectures rapidement :

```bash
# format de i2cget:
# i2cget -y <i2c-bus> <device-address> <command-byte> [mode]
# i2c-bus : le bus i2c sur le pi. 1 ou 0.
# device-address: l'adresse du device (identifié avec i2cdetect)
# command-byte : [optionel, depend du device] le registre à lire.

# Exemple avec module d'adc ADS7830 (ce qu'on a fait sur ESP32)
# 0x48 = adresse du ADS7830
# 0x84 = channel 0.
i2cget -y 1 0x48 0x84
```

## Intégrer i2c dans un script python

On peut utiliser le package SMBus pour utiliser le Pi comme master i2c.

Cela va nous permettre de communiquer directement avec d'autres appareils. L'utilisation de SMBus est relativement simple. [La documentation](https://pypi.org/project/smbus2/_) fournit plusieurs exemples.

**Exemple avec ADS7830 :** 

```python
from smbus2 import SMBus
import time

ADS7830_ADDRESS = 0x48

# Au lieu de calculer l'identifiant de commande dynamiquement, 
# on peut aussi se faire 
# Idx = channel
ADS7830_CHANNELS = [
	0x84, 0xC4, 0x94, 0xD4,
	0xA4, 0xE4, 0xB4, 0xF4, ]

def read_adc(bus, address, channel):
	# Comme sur l'esp32 : on commence en écrivant la commande de lecture pour notre channel
	bus.write_byte(address, ADS7830_CHANNELS[channel])
	
	# Ensuite on lit l'octet de retour
	return bus.read_byte(address)

def main():
	# La syntaxe `with X as Y` va gérer automatiquement la fermeture
	# du bus à la sortie du bloque
	with SMBUS(1) as bus:
		try:
			while True:
				v = read_adc(bus, ADS7830_ADDRESS, 0)
				print(f"ADC Channel 0 = {v}")
				time.sleep(0.1)
		except KeyboardInterrupt:
			# Quitte sur CTRL + C
			pass

# Façon typiquement pythonesque d'invoquer main
if __name__ == "__main__":
	main()
```

## Définir un ESP32 comme slave i2c

La lbirairie Arduino Wire peut être utilisée sur un ESP pour le faire fonctionner comme slave. Il peut donc être contrôlé par le Pi via i2c.

Les étapes nécessaires : 
- Appeler Wire.begin avec une adresse qui identifie notre ESP sur le bus i2c
- Enregistrer les callbacks onRequest et onReceive
	- NB : Les callbacks sont théoriquement optionelles, mais en vrai on va en vouloir au moins un des deux.


```arduino
#include <Wire.h>

constexpr uint8_t SLAVE_ADDRESS = 0x08;
std::atomic<uint8_t> storedValue = 0;

// Called when the master sends data.
void receiveData(int byteCount) {
  while (Wire.available()) {
    storedValue.storedValue(Wire.read()); // Keep the last received byte.
  }
}

// Called when the master requests data.
void sendData() {
  Wire.write(storedValue.load());
}

void setup() {
  Wire.onReceive(receiveData);
  Wire.onRequest(sendData);
  Wire.begin(SLAVE_ADDRESS);
}

void loop() {
  // Other work can run here.
}
```
