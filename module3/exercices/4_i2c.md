## Exercice 1 - Module ADC I2C

Votre trousse de composants contient un module ADC ADS7830.

<img src="img/Pasted image 20261001110223.png" width="400" />

Ce module permet de comparer des tensions à une tension de référence arbitraire et retourne une valeur sur 8 bits représentant comment elle se compare vis à vis la tension de référence.

**Caractéristiques :** 
- 8 entrées ADC
- Communication I2C
- S'adapte à des tensions à différentes tensions de référence.

**Branchements du ADS7830 :** 

<img src="img/Pasted image 20261001110535.png" width="400" />

- A0 à A7 : Entrées ADC.
- VCC : 3.3V
- SDA et SCL : Lignes I2C. 
- REF : Tension de référence (i.e. la tension maximale sur votre entrée ADC)
- GND : GND

### Exercice 1.1

Faites sur KiCAD un schéma pour le circuit suivant :
- Nous voulons utiliser le ADS7830 pour mesurer la tension de sortie d'un potentiomètre.
- Le potentiomètre va être branché au 3.3V de notre ESP32. La tension de référence va donc être de 3.3V.
- Le ESP32 va communiquer avec I2C avec le ADS7830. Utilisez les broches I2C par défaut (SDA=GPIO21 et SCL=GPIO22)

### Exercice 1.2

Assemblez ce circuit sur votre platine d'essai.

Programmez votre ESP32 pour réalisez les fonctions suivantes : 
- À chaque 500ms, lire la valeur retourné par le ADS7830 et l'imprimer sur la sortie série.

Utilisez la fonction suivante pour faire les lectures de l'ADC : 

```arduino
// Adresse habituelle du ADS7830
#define ADS7830_ADDR 0x4B

// Valeurs de sorties : -1 pour err, sinon entre 0 et 255.
// addr = adresse du module adc
// int channel = le canal de l'adc. A0 = 0, A1 = 1, ...
int ads7830_read_selected_channel(int addr, int channel)
{
	const int read_command_base = 0x84;
	
	// Transmet la commande de sélection de canal
	Wire.beginTransmission(addr);
	{
		// 3 bits dans l'octet de commande sont utilisés pour indiquer le canal de lecture
		// mais le mapping est un peu bizarre :
		// En considérant le nibble suivant : MSB C2 C1 C0
		// C2 = 1
		// C1 = 4
		// C0 = 2
		// Le canal 5 devient : MSB 1 1 0
		// Le canal 3 devient : MSB 1 0 1
		// Le canal 6 devient : MSB 0 1 1
		unsigned int arg_channel = (((channel << 2) | (channel >> 1)) & 0x07) << 4;
		unsigned char cmd = (unsigned char)((read_command_base | arg_channel) & 0xFF);
		Wire.write(cmd);
	}
	Wire.endTransmission();
	
	// Lit la réponse.
	Wire.requestFrom(addr, 1);
	if( !Wire.available() )
	{
		return -1;
	}
	
	return Wire.read();
}
```

N'oubliez pas d'initialiser la libraire `Wire`!

## Exercice 2 - Écran LCD I2C

Pour cet exercice, nous allons utiliser l'écran LCD inclut dans votre trousse. Cet écran est programable via I2C. Il doit être alimenté via du 5V (le 5V de votre ESP32).

Un petit potientiomètre à l'arrière permet d'ajuster l'éclairage de l'écran au besoin (le bloc de plastique bleu avec la petite vis)

<img src="img/Pasted image 20261001112005.png" width="400" />

L'utilisation de l'écran LCD peut quand même être complexe. Nous allons donc utiliser une librairie pour s'en occuper à notre place : 

<img src="img/Pasted image 20261001112248.png" width="400" />

Cette librairie utilise `Wire` pour la communication I2C.

Exécutez ce code dans la fonction setup de votre programme : 

```
#include <LiquidCrystal_I2C.h>
// 0x27 est typiquement l'adresse I2C de l'ecran. 
// Si ça ne fonctionne pas, essayez avec 0x3f ou 0x4b
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
	lcd.init(); // Initialize the LCD
	lcd.backlight(); // Turn on the backlight
	lcd.clear();
	lcd.home();
	lcd.print("Hello, World!"); // Print text
}
```

Plusieurs fonctions existent pour contrôler l'affichage. Par exemple, vous pouvez faire défiler le texte automatiquement ou même le faire clignoter.

[Le fichier d'en-tête liste les fonctions disponibles.](https://github.com/johnrickman/LiquidCrystal_I2C/blob/master/LiquidCrystal_I2C.h)
