# I2C

**I2C** ou **IIC** ou **Inter-Integrated Circuit** est un protocole à deux fils facilitant la communication entre deux circuit intégré (aussi appelé IC) .

**Caractéristiques du protocoles :** 
- Topologie Master/Slave par bus
- Protocole simple à deux fils 
	- SDA : Data. 1 bit à la fois synchronizer par clock.
	- SCL : Clock. Contrôler par Master. Utilisé uniquement lorsque nécessaire.
- Un unique bus I2C peut être partagé par plusieurs appareils
- Half duplex
- Les IC slave sont identifiés par une adresse unique. Deux IC avec la même adresse ne peuvent pas être sur le même bus I2C.

## Sur ESP32

Le ESP32 supporte l'utilisation de n'importe quel GPIO comme broche I2C (sda et scl). Cependant, les librairies Arduino vont typiquement s'attendre à ce que certains GPIO en particulier soit utiliser à cet effet : 
- SCL : GPIO22
- SDA : GPIO21

## Wire.h

`Wire` est la librairie utilisée par Arduino pour la communication I2C. Cette librairie est bloquante. C'est à dire que le flot de contrôle s'arrête jusqu'à ce que la réception/l'envoie des données soit complété.

**Setup :** 

```arduino
// En-tete de la librairie
#include <Wire.h>

void setup() {
	// La librairie doit etre initialise avant utilisation.
	Wire.begin();
}
```

**Enoie de message :**

```arduino
// Prépare la librairire pour la transmission de données. 
// Les trames résultantes vont toutes être envoyés à `adresse`
Wire.beginTransmission(adresse); 

// Fournit les données pour une trame.
Wire.write(cmd);

// Toutes les données ont été fournies à la librairie. Maintenant, on les envoie sur le bus.
Wire.endTransmission();
```

**Réception de message :**

```arduino
// Envoie vers adresse une demande de données.
// addr = adresse
// sz = nombre d'octet à recevoir. cette information est utilisée à l'interne uniquement et représente un maximum.
Wire.requestFrom(addr, sz);

// Wire.available indique s'il y a des octets de disponibles dans le buffer de réception.
// Chaque appel à read décrémente la quantité d'octet restant.
if( !Wire.available() )
{
	return -1;
}

// Lit un octet du buffer de réponse.
return Wire.read();
```
