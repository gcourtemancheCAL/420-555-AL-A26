# ESP 32

<img src="img/Pasted image 20260924090807.png" width="800" />

## Spécifications : 

**Processeur** : RISC 32 bits 160MHz à 240MHz, Xtensa **dual-core**

**WiFi** : 802.11 b/g/n 2.4GHz IPv4

**SRAM**: 520 Kio SRAM : 200Kio IRAM, 320Kio DRAM 

**Flash**: 4Mio

**Autres :** 
- Hardware SPI et I2C
- 2x modules ADC pour 16 cannaux ADC 

## Les broches

Le schéma fournit par le manufacturier est un peu limité. La documentation officielle d'espressif fournit beaucoup plus de détails sur les broches. 

[Voir section 2.2 - Pin Definitions / Pin Description](https://documentation.espressif.com/esp32-wroom-32_datasheet_en.html)

**Restrictions sur les broches :** 

| GPIO Pins                | Restriction    |                                                             |
| ------------------------ | -------------- | ----------------------------------------------------------- |
| **GPIO 6 – 11**          | Flash Memory   | Contrôle accès flash via SPI. Absent du devkit.             |
| **GPIO 0, 2, 5, 12, 15** | Strapping Pins | Détermine paramètres de démarrage.                          |
| **GPIO 34 – 39**         | Input-Only     | Disponible en entrée seulement.                             |
| **GPIO 1, 3**            | UART0 / Serial | Utilisé pour communication série : logs et flasher le ESP32 |
